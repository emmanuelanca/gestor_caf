# Configuración inicial

Antes de hacer cualquier cosa, se deben crear los archivos `.env`, que cada uno tiene en su propia PC y **no se deben subir** al repositorio.

## En archivo `server/.env`

```
DB_HOST=ip de la base de datos
DB_USER=user
DB_PASSWORD=contraseña de db
DB_NAME=club_french
```


## En archivo `client/.env`

```
VITE_API_URL=http://ip de tu pc:5000
```
